A static, searchable reader for the Algebraic Number Theory (MATH60042) 2026 deferred
examination cheat sheet.

**Site:** https://why-op109.github.io/algebraic-number-theory-deferred-2026/

- 231 recall cards derived from the live canonical sheet
- 13 closed-book formulas in 4 categories and 9 standard exam moves

- Mathematics rendered at build time to accessible KaTeX HTML + MathML
